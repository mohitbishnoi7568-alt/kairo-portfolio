A better command line setup

Jul 9, 2026 · 5 min read · Kairo

I did not need a new terminal emulator. I needed the one I already had to stop feeling like a scratchpad. Five small changes did more than any theme pack.

A prompt that tells you where you are

Path, git branch and a marker for whether the working tree is clean. That is enough. Anything longer pushes the command you are typing off the screen.

# a compact prompt idea
PS1='\w$(git branch --show-current 2>/dev/null | sed "s/^/ [\&]/") \$ '

Aliases for the nouns, not the verbs

Short names for places you go often beat clever shortcuts for commands you already know. Keep the alias list short enough to memorise.

alias notes='cd ~/notes'
alias proj='cd ~/projects'
alias ..='cd ..'

Searchable history

Turn on history search with the up arrow and let the terminal remember more than a few hundred lines. Half my command line life is finding a command I already got right once.

The best shortcut is the command you do not have to retype.

Wrap up

A useful prompt, a few aliases and a searchable history. None of it is fashionable, all of it gets used every day.
