Getting started

This site is a static portfolio: four HTML pages, one stylesheet and one small JavaScript file. There is no build step and no dependency to install. Open index.html in a browser, or serve the folder with any static file server.

The name and email are already set to Kairo and noviqxofficial@gmail.com. Replace the project cards and post titles with your own details.

Setup

To preview locally with Python, run a server in this folder:

python3 -m http.server 8000

Then open http://localhost:8000. On a phone, any static hosting service will work — upload the folder as-is.

  • index.html — portfolio home
  • blog.html — post archive with topic filters
  • post.html — a single article
  • docs.html — this page
  • css/style.css — all styling
  • js/main.js — navigation, filters, copy button, TOC highlighting

Projects

The home page shows three project cards. Each card has a small gradient thumbnail, a category tag, a two-line description and a link. Duplicate the <article class="card"> block to add more.

Use a real image later by replacing the .thumb div with an <img> and adding a matching CSS rule.

Writing

Posts are plain HTML. The archive filters them using data-category attributes and the buttons in the sidebar; you do not need a database or a CMS. Add a new post by copying a .list-item block and setting a new date and category.

The reading view has a table of contents on the right. Its links point to heading IDs, and js/main.js highlights the heading currently in view.

Colophon

Set in the system UI font. No web fonts, no icons from a CDN, no tracking scripts. The light palette lives in a handful of CSS variables at the top of css/style.css, so changing the accent color takes one edit.
