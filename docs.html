Getting started

This is a static site: HTML pages, one stylesheet and one small JavaScript file. There is no build step and no dependency to install. Open index.html in a browser, or serve the folder with any static file server.

The name and email are already set to Kairo and noviqxofficial@gmail.com. Replace the project cards and the "Based in" field with your own details.

Setup

To preview locally with Python, run a server in this folder:

python3 -m http.server 8000
# then open http://localhost:8000
  • index.html — portfolio home
  • blog.html — post archive with search, filters and saved posts
  • posts/*.html — individual articles
  • docs.html — this page
  • 404.html — custom not-found page
  • css/style.css — light and dark palettes, all layout
  • js/main.js — theme, search, progress, sharing, offline registration

Projects

The home page shows three project cards. Each card has a gradient thumbnail, a category tag, a two-line description and a link to a related note. Duplicate the <article class="card"> block to add more.

Writing

Posts are plain HTML files in posts/. The archive filters them using data-category and data-search attributes; starring a post stores its id in localStorage, so the Saved list works with no account or backend.

Each article has a table of contents on the right, a reading progress bar, a share button and copy-link buttons on headings.

Built-in features

  • Light pink theme plus a dark mode toggle that remembers your choice
  • Search (press /) and topic filters on the blog
  • Save posts for later on this device
  • Reading progress, share button and copy-link on articles
  • Contact form that opens your email app — nothing is stored
  • Offline support through a service worker
  • Installable as a PWA with icons and a manifest
  • Social preview cards, sitemap, robots.txt and RSS feed
  • Responsive layout, keyboard focus states, print styles and reduced-motion support

Updating the live site

The live copy is published on GitHub Pages from a kairo-portfolio repository. After editing local files, upload the changed files to the repository again and Pages will rebuild in under a minute.

If you change file names or add pages, update sw.js too: bump the cache version (for example v1 to v2) and add the new paths to its asset list. That makes returning visitors fetch the fresh version.

Colophon

Set in the system UI font. No web fonts, no trackers, no external scripts. The palettes live in a handful of CSS variables at the top of css/style.css, so changing the accent colour takes one edit.
